SAFE DEPLOY FLOW

Update without touching layout code

  1. Choose a content type, then use New record or load an existing record.
  2. Select an image. The Studio creates a safe filename and website path.
  3. Generate the record and fix any red validation errors.
  4. Use Download complete content file to avoid manual commas and brackets.
  5. Use Download renamed image if you selected a new image.
  6. Replace only that content file and upload only the matching image.
  7. Open this Studio again and confirm the validator reports no structural errors.
